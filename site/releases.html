01 / WHAT CHANGEDЧТО СДЕЛАНО

Less friction.
More confidence.Меньше помех.
Больше уверенности.

RC1 includes the stability work from 8.5.1. Existing creative tools remain available; no proposed feature below is presented as shipped.В RC1 включены исправления версии 8.5.1. Творческие инструменты сохранены; будущие функции ниже явно отмечены как предложения.

01 / IMPROVEDУЛУЧШЕНО

Safer image loadingНадёжнее загрузка изображений

Large panoramas and tall scans now decode within a memory budget. Low-memory devices use a smaller image limit. Gallery thumbnails use the same sizing protection.Большие панорамы и длинные сканы загружаются с ограничением памяти. На слабых устройствах лимит ниже. Та же защита действует для миниатюр галереи.

02 / IMPROVEDУЛУЧШЕНО

Less repeated filter workМеньше лишней работы фильтров

Obsolete pixel calculations stop when settings change. CPU filters share one work lane, and changing outline strength no longer rebuilds the same pixels.Устаревшие расчёты прекращаются при смене настроек. Тяжёлые фильтры обрабатываются последовательно, а изменение силы контура не пересчитывает те же пиксели.

03 / IMPROVEDУЛУЧШЕНО

A workspace that remembersВосстановление рабочей сессии

The last accessible image is restored. Settings writes are grouped, and the latest adjustments are saved when you leave the app. Folder access is recognized correctly.Последнее доступное изображение восстанавливается. Записи настроек объединены, последние изменения сохраняются при выходе. Доступ через выбранную папку учитывается корректно.

04 / IMPROVEDУЛУЧШЕНО

Predictable remote controlsПредсказуемое управление пультом

Back closes the current controls and eventually returns to the TV launcher. Movement stays within supported bounds, and Keep Screen Awake follows your setting.«Назад» закрывает текущие элементы управления и затем выводит на главный экран TV. Смещение остаётся в допустимых пределах, а активность экрана соответствует настройке.

05 / IMPROVEDУЛУЧШЕНО

Correct image orientationПравильная ориентация фотографий

Mirrored EXIF rotations are corrected. Orientation works on Android 6, and legacy Android versions now support the advertised overlay blending modes.Исправлены зеркальные EXIF-повороты. Ориентация работает на Android 6, а старые версии Android поддерживают заявленные режимы наложения.

06 / IMPROVEDУЛУЧШЕНО

A leaner release buildБолее компактная сборка

The fixed startup wait is reduced from 3 seconds to 350 ms. Unused release code and resources are removed. Privacy information is available in the app and on this website.Фиксированная стартовая пауза сокращена с 3 секунд до 350 мс. Неиспользуемые код и ресурсы удалены из релизной сборки. Политика конфиденциальности доступна в приложении и на сайте.

02 / BEFORE STABLEДО СТАТУСА STABLE

Tested in an emulator.
Next: the studio.Проверено в эмуляторе.
Дальше — мастерская.

An automated check is evidence, not universal compatibility. These checks remain open before declaring Stable 0.9.Автоматическая проверка — подтверждение конкретного сценария. Эти проверки ещё нужны, чтобы объявить Stable 0.9.

TO VERIFYПРЕДСТОИТ ПРОВЕРИТЬ

Projectors in real useРеальные проекторы

Record models and Android versions. Include low-memory hardware and a sustained drawing session.Зафиксировать модели и версии Android. Проверить слабое устройство и длительную сессию рисования.

TO VERIFYПРЕДСТОИТ ПРОВЕРИТЬ

Files, USB and recoveryФайлы, USB и восстановление

Test unplugging USB, slow file providers, revoked permissions, missing files and repeated restarts.Проверить отключение USB, медленные файловые браузеры, отзыв разрешений, потерю файлов и повторные запуски.

TO VERIFYПРЕДСТОИТ ПРОВЕРИТЬ

Release and store checksРелиз и магазин

Verify permanent signing and updates, a 16 KB runtime, and Google Play permissions and account requirements.Проверить постоянную подпись и обновление, работу с памятью 16 КБ, разрешения и требования аккаунта Google Play.

Undo / RedoОтмена и повтор

Recover an accidental alignment or filter change without resetting your work. Held remote keys should count as one edit.Вернуть случайно изменённое положение или фильтр без полного сброса. Удержание кнопки пульта — одно действие в истории.
